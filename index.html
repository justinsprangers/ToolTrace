Photo
Tips for a good photo
  • Plain white paper is the most reliable reference; tabloid or poster board for long tools.
  • Shoot straight down from high up with 2–3× zoom.
  • Even light, no hard shadows; tools not touching.
  • Several tools per photo is fine: each becomes its own shape.
Scale reference
  • Orange handles go on the paper corners.
  • Use the size of the smallest squares.
  • Check the blue grid drawn over the photo.
If detection fails

Put the 4 orange handles on any 4 grid crossings and type how many squares are between them. The handles snap to the nearest crossings. Many mats have ½-inch lines between the inch labels.

  • Orange handles go on the corners of any rectangle of known size.
  • Green handles mark where the tools are. Only that area is traced.
When to use a work area

Without one, only the reference itself (the paper or grid area) is traced. Use a work area when tools hang past the reference, or to skip clutter around it. It can be bigger or smaller than the reference.

Trace settings
Which slider to change
  • Shadows or grid lines traced → raise Sensitivity or lower Brightness weight.
  • Shiny or pale parts missed → lower Sensitivity.
  • Tools merging → lower Bridge gaps.
  • Remove thin lines is for mat grids; keep it 0 on paper.
Fix up
  • Brush keep / erase (B / E): add or remove what you paint.
  • [ ] brush size · Ctrl+Z undo.
Shapes
  • Untick to leave a shape out.
  • Click a shape to select it and edit its nodes.
Outline settings for all shapes
What these do
  • Corners (cyan) stay sharp.
  • Smoothing only removes noise between corners.
  • Straight runs become exact lines; curves stay curves.
  • Node detail: lower = more nodes, closer to the trace.
Shape
  • Halves averaged across the pink axis; edits mirror on release.
Editing nodes
  • Drag a node to move it; click the outline to add one.
  • Double-click or C: corner ■ / smooth ●.
  • L: straight line to the next node.
  • Delete: remove node (or exclude the shape if no node is selected).
  • Esc: deselect.
Save to library
  • Saved as “prefix + shape name”, e.g. tool Shape 1.

Moving and rotating
  • Drag to move; drag the round handle to rotate (Shift snaps 15°).
  • Arrows nudge, R rotates 90°, Delete removes.
Finger notches
  • Pick Notch (N), then click; it snaps to tool edges.
  • Click a notch to select it; Delete removes it.
More about notches
  • Hold Alt to place without snapping.
  • A snapped notch moves and rotates with its tool and is never deeper than it.
  • With a symmetry axis, a mirrored twin is added; deleting one deletes both.
  • In Notch mode, clicking an existing notch removes it.

About the pieces
